# Mermaid Diagrams

These files contain simple Mermaid diagram code for explaining the FarReach Tourism Explorer project.

## Files

- `use-case-diagram.mmd` - main actors and system use cases
- `database-schema.mmd` - database ER diagram
- `dfd-level-0.mmd` - context-level DFD
- `dfd-level-1.mmd` - major system processes and data stores
- `dfd-level-2-authentication.mmd` - detailed authentication and OTP flow
- `dfd-level-2-booking-review.mmd` - detailed booking, saved spot, and review flow

## How to View

Paste any `.mmd` file into the Mermaid Live Editor:

https://mermaid.live
